# Dodge the Block - Python Game

A 2D survival arcade game built with Python and the Pygame library. This project demonstrates core game development concepts including game loops, event handling, and collision physics.

## 🛠️ Key Technical Features
* **Dynamic Difficulty:** Implemented logic to increase enemy speed based on the player's score.
* **Asset Pipeline:** Managed external PNG sprites and background textures with real-time scaling.
* **Collision Detection:** Developed a custom collision system using coordinate-based hitbox math.
* **Game State Management:** Handled game initialization, main loop execution, and "Game Over" states.
